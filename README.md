# 離校下一班

長庚大學離校資訊的免登入手機網頁：接下來 3 班家豪（含週五加班車、是否繞明德）、967／967 直／202／603 班表與官方動態連結、尖峰提示、排隊圖解與替代方案。

本頁**非**長庚大學官方網站，班次以總務處與公路主管機關公告為準。

## 現況

規格見 [`spec.md`](./spec.md)。頁面內容已齊（含尖峰提示、排隊圖解、替代方案、頁尾）。請先在本機預覽，不要把這個 repo 設成正式網站或自動部署。

## 本機預覽

純靜態，不需安裝任何套件：

```sh
python3 -m http.server 8000
```

然後用瀏覽器開 <http://localhost:8000>（手機寬度 375px 以上為單欄）。無登入、無 cookie、無分析工具。

## 請不要

未再取得明確同意前，請不要部署（含 Vercel、GitHub Pages、自訂網域）、申請或使用 TDX 金鑰、加入分析工具，或對外推廣。

## 測試

`node --test tests/*.test.js`（無相依套件）。頁面需透過靜態伺服器開啟（例如 `python3 -m http.server`），因為會 fetch 資料檔。
